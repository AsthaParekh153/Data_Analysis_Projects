# 📊 Data Analysis Projects | Python | NumPy | Pandas | Matplotlib | Seaborn

## 📌 About This Repository

This repository contains my hands-on Data Analysis projects using Python and its popular data analysis and visualization libraries.

These projects demonstrate my skills in data cleaning, data preprocessing, Exploratory Data Analysis (EDA), statistical analysis, data manipulation, and visualization to extract meaningful insights from datasets.

## 🛠️ Technologies & Libraries

- **Programming Language:** Python
- **Libraries:** NumPy, Pandas, Matplotlib, Seaborn
- **Environment:** Jupyter Notebook / Google Colab

## 📂 Projects

### 1. Boston Housing Data Analysis

**Technologies:** Python, NumPy, Pandas, Matplotlib, Seaborn

- Analyzed housing data to identify patterns in house prices, room counts, and other housing variables.
- Performed data cleaning, duplicate removal, data type checks, filtering, and correlation analysis.
- Conducted statistical analysis using mean, median, minimum, maximum, and standard deviation.
- Created visualizations including histograms, scatter plots, bar charts, and boxplots to identify trends and relationships.

### 2. Movie Data Analysis

**Technologies:** Python, NumPy, Pandas, Matplotlib, Seaborn

- Analyzed 10,866 movie records to explore trends in budget, revenue, profit, popularity, runtime, genres, and ratings.
- Cleaned and prepared data by handling missing values, duplicates, unnecessary columns, and data types.
- Calculated movie profit using Revenue − Budget.
- Performed Exploratory Data Analysis (EDA) and statistical analysis using charts and visualizations to identify meaningful patterns.

### 3. Zomato Restaurant Data Analysis

**Technologies:** Python, NumPy, Pandas, Matplotlib, Seaborn

- Analyzed restaurant data to identify patterns in ratings, restaurant types, customer votes, cost, online ordering, and table booking.
- Cleaned and prepared data by handling missing values, duplicates, data types, and converting ratings into numeric format.
- Performed grouping, sorting, and statistical analysis to explore restaurant performance.
- Created visualizations using Matplotlib and Seaborn to identify rating, cost, popularity, and service-related trends.
